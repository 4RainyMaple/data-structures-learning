## 摊还分析

摊还分析的意义：某个操作虽然最坏情况下很慢，长期连续使用时仍然高效。  

以哈希表为例：  
假设哈希表容量装满才扩容，每次翻倍：从 1 扩到 2、4、8……插入到大约n个元素时，扩容需要搬运的元素数量大致是：  

```math
1+2+4+\cdots+2^k=2^{k+1}-1
```

而最后一次扩容前的容量$`2^k`$小于$`n`$，所以 $`2^{k+1}<2n`$。因此搬运时间是$`O(n)`$。  

再加上 $`n`$ 次插入本身的工作，总时间仍是 $`O(n)`$。平均到每次插入，就是$`O(1)`$。  

## 上界分析

摊还分析可以给不同类型的操作分别设定摊还代价，只要这些代价加起来始终不小于实际总成本，就能用它们来界定整串操作的总时间。  
比如2-3树（一种类似于AVL树的平衡树），它的插入和删除时间均为$`O(logN)`$，创建空树的时间为$`O(1)`$，设创建空树的次数为$`c`$，插入的次数为$`i`$，删除的次数为$`d`$，则总时间为  

```math
O(c+ilogN+dlogn)
```

由于$`d \leq i`$，总时间的上界为  

```math
O(c+ilogN)
```

这样我们可以认为删除的代价为0，它的代价都被插入所承担了。  

## 记账法

将时间开销视作花钱，比如插入的时候我们除了支付本身的开销，还要存一些钱到一个银行里面，等到后续需要昂贵开销时我们就调用这笔钱。  
比如数组扩容，由于前半部分的位置的存款用于给后半部分扩容，因此数组中只有后半部分，即一半的位置有存款，设存款为$`c`$，则$`c`$足够大时，有  

```math
\Theta(N)-c\frac{n}{2}=0
```

即扩容开销为0，显然$`c`$是一个常数。  

## 收费法

当昂贵操作发生后，把它的成本分配给此前的一批操作。  
还是以数组扩容为例，将$`\Theta(N/2)`$的空间搬运的开销可以向后续$`\Theta(N/2)`$的插入收费，每个位置只需收费$`O(1)`$，这两种方法都能证明数组连续插入的开销是线性的，即数组连续插入是高效的操作。  
再来看数组缩容，设数组填充25%才缩容，这样的好处是，无论是扩容还是缩容，操作完成后数组的填充率都是50%，等到下次扩容或缩容时，需要经历$`\Theta(N)`$次插入或删除，那么缩容搬运的开销就向这些操作收费。如此，数组连续扩容或删除都是线性开销。  

## 势能法

把数据结构当前积累的工作写成一个函数$`\Phi`$，便宜操作增加势能，昂贵操作消耗势能，即  

```math
\text{摊还代价} = \text{实际代价} +\Delta\Phi
```

显然，若势能始终非负，则总摊还代价至少覆盖总实际代价。因此，只需要证明每次操作的摊还代价为$`O(1)`$，就能推出整串操作的总时间是线性的。  
例如：二进制计数器  
假设一个二进制数末尾有$`t`$个连续的1，那么这时加一，会导致一连串的改变。定义势能函数$`\Phi`$为二进制数中1的个数，那么看每次加一会导致末尾$`t`$个1全部翻为0，倒数$`t+1`$位的0会翻为1，那么实际开销可以表示为$`t+1`$，而1的个数减少了$`t`$个又增加了1个，即  

```math
摊还开销=t+1-t+1=2
```

如此我们就可证明二进制加法器连续加一的开销是线性的。
