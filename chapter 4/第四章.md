## 4.1

树的递归定义：  
树是节点的集合。若树不是空集，则由根的节点r和多个子树组成。  
每一棵子树的根记作根r的儿子，r是每一棵子树的父亲，没有儿子的节点称为树叶。  
一棵树是n个节点和n-1边的集合。  
从节点$`n_1`$到$`n_k`$的路径定义为$`n_1`$到$`n_k`$的一个序列，则$`n_i`$是$`n_{i+1}`$的父亲。  
路径的长定义为路径上边的个数。  
节点的深度定义为根到该节点的长（唯一）。  
节点的高定义为该节点到树叶的最长路径的长，一棵树的高等于根的高。

## 4.4

### AVL树

定义：**每个节点**的左右子树深度差最多为1的二叉查找树。其中空树的高度定义为-1。

因此，给定树的高度 $h$，最少节点数 $S(h) = S(h-1)+S(h-2)+1$，其中1表示根节点，另外两项表示两棵子树的节点数，容易看出这是斐波那契数列的变形。

由于树的高度为 $O(\log N)$，因此除了插入删除等操作以外的操作时间复杂度基本都为 $O(\log N)$。而插入删除操作可能破坏AVL树的平衡结构，因此需要修正树——旋转。

## 4.7 B 树

**1. 为什么需要B树：**  
数据太多，需要储存在磁盘上，磁盘访问代价高，因此希望树的分支尽可能多，如此查找次数更少。  

**2. B树的核心结构：**  
设 M 为一个内部节点最多拥有的孩子数，L 为一个叶子最多存储的数据项数。  
则B树的核心部分满足以下规则：

- 数据储存在叶子中，所有叶子深度相同。
- 内部节点存放指路的关键字（用于比较大小，方便查找的值，即路标），有k个孩子就  有k-1个关键字。  

比如：该节点有4个关键字，因此有5个孩子

<img src="./images/b-tree-internal-node-keys-and-children.png" alt="B树内部节点的4个关键字与5个孩子" width="250">

- 非根叶子至少 ⌈L/2⌉ 个数据项
- 非根内部节点至少 ⌈M/2⌉ 个孩子
- 非叶子的根至少2 个孩子  

**3. B树的查找规则：**  
根据关键字进入孩子，一直找到叶子才能确定数据是否存在。  

**4. B树的插入：满了就分裂**

- 未超过 L 项：直接完成。  
- 超过 L 项：分成两个叶子，父节点增加一个孩子并更新关键字。  
- 父节点也超限：继续向上分裂。  
- 根也分裂：建立新根，树高增加 1。  

**5. 删除：不够就借，借不到就合并**  
找到叶子并删除数据后：

- 大于等于最低数量：完成，必要时更新指路关键字。

更新关键字举例：

```text
 删除前：
          [20]
         /    \
 [5,10,15]  [20,25,30,35]

 删除后：
          [25]
         /    \
 [5,10,15]  [25,30,35]
```

- 低于最低数量：向有余量的相邻兄弟借。  
- 兄弟也没有余量：合并，父节点减少一个孩子。  
- 父节点孩子因此不足：继续向上调整。  
- 根只剩一个孩子：让孩子成为新根，树高减少 1。

## 4.8

STL中的set和map

### set:不允许重复元的有序容器

#### 插入函数insert，这个函数的返回值并非bool那么简单，而是返回一个`std::pair<iterator,bool>`，传入参数也有两种方式

```cpp
std::pair<iterator,bool> insert ( const Object & x );
std::pair<iterator,bool> insert ( iterator hint , const Object & x );
```

如果我们已经知道插入元素应该在的位置，调用第二种重载效率会更高

#### 删除函数erase提供三种重载

```cpp
std::size_t erase ( const Object & x );   //返回删除元素的个数
iterator erase ( iterator itr );
iterator erase ( iterator start , iterator end );
```

#### 查找函数find

```cpp
iterator find ( const Object & x ) const;
```

**值得注意的是，由于set容器是有序容器，其自带的find函数使用二分查找，效率是高于逐个比对的标准算法库中的find函数**

### map:按关键字排序的键值对容器

#### 索引重载[]

**这是map容器的一个显著特征及优势**

```cpp
ValueType & operator [] ( const KeyType & key );
```

若key值不存在于map容器中，则会自动添加，并给value值赋默认值

注意这个函数并没有只读版本，意味着常量引用的map无法调用

#### 插入函数insert，与set的类似

```cpp
std::pair<iterator,bool> insert
( const std::pair < KeyType, ValueType > & x );
```

#### 查找函数find，与set类似，其中iterator解引用后是std::pair

```cpp
iterator find ( const KeyType & key );
const_iterator find ( const KeyType & key ) const;
// const_iterator 是限制修改元素，const iterator 是限制迭代器移动
```

#### 删除函数erase，与set的类似

```cpp
std::size_t erase ( const KetType & key );
iterator erase ( iterator pos );
iterator erase ( iterator start , iterator end );
```
