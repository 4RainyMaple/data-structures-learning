本章主要介绍4种常见的表容器：包括vector, list, stack, queue

list 与 vector 容器对比：

|        | 优点     | 缺点            |
| ------ | ------ | ------------- |
| vector | 索引O(1) | 增删O(N) 查找O(N) |
| list   | 增删O(1) | 索引O(N) 查找O(N) |

接口：

所有STL容器都支持的接口：  
int size() const;   void clear();   bool empty() const;

vector 和 list 都支持的接口：
void push_back ( const Object & ele );

void pop_back ( const Object & ele );

const Object & back () const;

const Object & front () const;

仅list支持的接口：

void push_front ( const Object & ele );

void pop_front ();

仅vector支持的接口：

Object & operator [] ( int index );  无界限检查

Object & at ( int index );           有界限检查

int capacity () const;

void reserve ( int newCapacity );

迭代器：

对于所有支持迭代器的容器，均可通过begin()和end()来返回迭代器

对于vector和list，可通过迭代器进行增删操作：

void insert ( iterator pos, const Object & ele ); //在pos前添加

void erase ( iterator pos );

void erase ( iterator start, iterator end );  //左闭右开区间

stack:

增删元素均在top进行，也称LIFO容器

queue:

基本操作：enqueue和dequeue
