## 教材参考：《数据结构与算法分析 C++语言描述》（4th.Mark Allen Weiss.2016）  
这是一本很全面的教科书，理论内容和代码实现兼具。  
前两章是预备知识，第三章至第六章为数据结构部分，包括4种常见的表容器、各种树、哈希表和堆，第七章至第十一章为算法部分，涵盖排序、不相交集合、图论、常见算法设计以及摊还分析。最后一章介绍了一些高级的数据结构，我只学习了红黑树的机制，以及简单实现了treap。  
但正是由于过于全面细致，对于新手入门不太友好，本人也是在AI的帮助下才勉强完成主干内容的学习，习题部分暂时跳过。  
关于为什么我选择这本书，主要原因是没有特别中意的C++描述的网课，几门比较好的数据结构与算法课程都是Java或者Python描述的。虽然简单掌握一门编程语言并不困难，但是对于刚学完C++的我而言，实在难以接受再学一门新的编程语言。因此，我学习数据结构与算法的主线也是跟着这本教材走的。

## 课程参考：MIT 6.046J  
这门课程的定位是完全的算法理论课程。  
相较于教材极其晦涩的文字解释算法，这门课程用黑板手写解析算法显然更有利于理解。  
其中涉及许多数学推导，难度不小。
